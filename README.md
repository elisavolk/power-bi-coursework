# Power BI Coursework

Power BI coursework from the IT Academy Data Analytics program.

This repository contains an introductory Power BI dashboard exercise focused on report layout, KPI cards, slicers, maps, time-based visuals, customer and product summaries, and basic DAX measures.

## Contents

- `sprint-07-power-bi-basics`: guided dashboard exercise using online sales transaction data.

## Skills Demonstrated

- Power BI report layout and visual formatting
- KPI cards, slicers, maps, tables, bar charts, line charts, and gauge visuals
- Data model organization with transaction, user, company, product, and date-related tables
- Calendar/date table usage for time-based analysis
- Basic DAX measures for totals, averages, counts, targets, and filtered calculations
- Use of a separate measures table for report calculations
- Introductory many-to-many handling through a transaction-product bridge table

## Notes

This repository contains coursework, not a full production BI solution. It is included to show early Power BI practice and dashboard-building progression.

Power BI `.pbix` files cannot be previewed directly in GitHub. Open them with Power BI Desktop to inspect the report.

## Resumen en castellano

Coursework de Power BI realizado como parte del programa de Data Analytics de IT Academy.

Este repositorio contiene un ejercicio introductorio de dashboard en Power BI, centrado en diseño de informes, tarjetas KPI, segmentadores, mapas, visualizaciones temporales, resúmenes de clientes y productos, y medidas DAX básicas.

## Contenido

- `sprint-07-power-bi-basics`: ejercicio guiado de dashboard usando datos transaccionales de ventas online.

## Competencias trabajadas

- Diseño y formato visual de informes en Power BI
- Tarjetas KPI, segmentadores, mapas, tablas, gráficos de barras, líneas y medidores
- Organización del modelo de datos con tablas de transacciones, usuarios, empresas, productos y fechas
- Uso de tabla calendario para análisis temporal
- Medidas DAX básicas para totales, medias, conteos, objetivos y cálculos filtrados
- Uso de una tabla separada de medidas
- Manejo introductorio de una relación muchos-a-muchos mediante una tabla puente entre transacciones y productos

## Notas

Este repositorio contiene coursework, no una solución BI de producción. Se incluye para mostrar práctica inicial en Power BI y progresión en la creación de dashboards.

Los archivos `.pbix` no se pueden previsualizar directamente en GitHub. Para inspeccionar el informe, hay que abrirlo con Power BI Desktop.
