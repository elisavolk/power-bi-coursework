# Power BI Coursework

Power BI coursework from the IT Academy Data Analytics program.

This repository presents two Power BI reports as learning projects. The work shows progression from a guided dashboard-building exercise to a more open-ended sales analysis focused on trends, patterns, and business interpretation.

The original `.pbix` files are included with clearer names and folder organization. These reports are coursework artifacts, not production BI solutions, but they demonstrate report design, visual analysis, basic DAX, data modelling, and dashboard storytelling.

## Contents

- `sprint-07-power-bi-basics`: guided dashboard exercise using online sales transaction data.
- `sprint-08-sales-analysis`: sales analysis report focused on sales behavior over the last five years.

## Skills Demonstrated

- Power BI report layout and visual formatting
- KPI cards, slicers, maps, tables, bar charts, line charts, gauge visuals, and tooltip pages
- Data model organization with transaction, user, company, product, and date-related tables
- Basic DAX measures for totals, averages, counts, targets, and filtered calculations
- Time-based sales analysis
- Geographic and customer-focused analysis
- Dashboard storytelling and visual interpretation

## Notes

Power BI `.pbix` files cannot be previewed directly in GitHub. Open them with Power BI Desktop to inspect the reports.
